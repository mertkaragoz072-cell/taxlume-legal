# assets / app_icon

CLASHBORN LEGENDS ikonu. Kaynak: `../../references/clashborn_app_icon_source.webp` (1254×1254, tam kare, şeffaflıksız).

Tümü 1024×1024 px.

| Dosya | Kullanım |
|---|---|
| `app_icon_1024_opaque.png` | **iOS/App Store ve genel mağaza ikonu.** Tam kare, **alfasız** RGB (kaynaktan 1024'e küçültüldü). OS köşeleri kendisi yuvarlar. |
| `app_icon_1024.png` | RGBA kopya (alfa kanalı tamamen opak). Önizleme/web için. |
| `app_icon_adaptive_foreground.png` | **Android adaptive icon ön katman.** Şeffaf; ikon sanatı orta %66'da (güvenli alan). |
| `app_icon_adaptive_background.png` | **Android adaptive icon arka katman.** Aynı sanatın bulanıklaştırılmış hali. |

Not: İkondaki yazı "CLASHBORN LEGENDS". Android ön katmanda yazı küçülür; istenirse Android için ayrı bir ön katman üretilebilir.
