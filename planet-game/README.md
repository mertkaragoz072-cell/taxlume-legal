# Planet Warrior (prototip)
Çalıştırma: `cd planet-game && python3 -m http.server 8080` → http://localhost:8080 (veya index.html'i doğrudan aç).
Kontrol: A/D veya ←/→, mobilde ekrana dokunup sürükle (sanal joystick). Tüm ayarlar `game.js` içindeki `CONFIG`'te.
Sprite eklemek için `Assets.manifest` içine `{ goblin: 'assets/goblin.png' }` gibi kayıt ekle.
