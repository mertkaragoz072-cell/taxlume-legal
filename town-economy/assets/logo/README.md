# Golden Town — logo

Everything here is generated by `scripts/build-logo.js`. Edit that script and
re-run it; do not hand-edit the SVGs, or the family drifts out of alignment
with itself.

```bash
npm --prefix /tmp/logo-tools install opentype.js@1.3.4
NODE_PATH=/tmp/logo-tools/node_modules:/opt/node22/lib/node_modules \
  node scripts/build-logo.js
```

**Pin opentype.js to 1.x.** Version 2.0.0 ignores the `letterSpacing` option,
so the tracking silently does nothing, and it writes `NaN` into the
coordinates of some glyph outlines in both of these fonts. An SVG path is
invalid from its first `NaN` onward, so a browser draws part of a letter and
abandons the rest — Ü came out as a bare diaeresis and Y as a single
diagonal, in files that looked perfectly well-formed. The script refuses to
write a file containing `NaN`, so a regression here fails loudly.

## The design

The mark is three buildings of rising height on a common base: a town if you
read the roofs, the columns of a rising chart if you read the bodies. Equal
widths carry the chart, pitched roofs carry the town.

The treatment is what makes it a game logo rather than an app icon — a heavy
keyline that holds the shape against any background, a rim that reads as the
cut edge of struck metal, a lit face and a sheen. The title sits on a gentle
arch for the same reason: a dead-flat baseline reads as a page header.

Two earlier attempts are worth not repeating. Bare chevrons with no bodies
read as a mountain range. A flat gold mark with elegant Roman capitals read
as a banking app.

## Two directions

There are two icons here on purpose, and they are not variations of each
other — pick one.

`icon.svg` is the **relief mark**: the brand, dark and gold, matching the
game's own interior. It is quiet, it scales, and it sits beside the wordmark.

`icon-character.svg` is the **store icon**: one big smiling merchant holding
up a coin over a bright town, in the idiom casual and idle games actually use
on the App Store — a face, saturated colour, a silhouette that still reads at
38px. It shares nothing with the relief mark but the subject.

The relief mark is the better *logo*. The character icon is the better
*listing thumbnail*, because store browsing rewards a face over a monogram.
Most games in this genre ship exactly this split.

`icon-character.svg` is hand-authored and is **not** produced by
`scripts/build-logo.js` — edit it directly; re-running the script leaves it
alone.

## Which file to use

| File                          | Use                                                          |
| ----------------------------- | ------------------------------------------------------------ |
| `logo-stacked-<lang>.svg`     | The main logo. Title screen, splash, store art, press.        |
| `logo-horizontal-<lang>.svg`  | Wide spaces: headers, footers, banners. Flat baseline.        |
| `icon.svg` / `icon-1024.png`  | Relief app icon — the mark on the dark plate.                 |
| `icon-character.svg`          | Casual-game store icon — character, coin, bright town.        |
| `mark.svg`                    | Mark alone in relief, transparent ground.                     |
| `mark-mono.svg`               | Flat, one colour via `currentColor`. Favicons, print, stamps. |
| `mark-dark.svg`               | Flat dark, for light backgrounds.                             |

`<lang>` is `tr` (ALTIN KASABA) or `en` (GOLDEN TOWN).

## Rules

**The relief needs room.** Below roughly 64px the keyline and rim collapse
into each other — use `mark-mono.svg` at favicon sizes instead of shrinking
the relief version.

**On light backgrounds** use `mark-dark.svg`, or put the relief logo on a dark
panel. The gold face has almost no contrast against cream.

**Colours come from `src/theme.ts`.** The face ramp is built around
`GOLD_GRADIENT`, the plate from the app's background browns, the flat dark
from `COLORS.onLight`. Change the theme's gold there and re-run the script.

**Clear space:** keep at least the width of one building body clear on every
side.

**The icon PNG is square on purpose.** Both stores apply their own corner
mask; baking a radius in leaves a pale halo inside theirs.

**Do not** restretch the wordmark, re-space it by hand, flatten the relief to
a single colour, or drop the arch from the stacked lockup. Tracking and arch
are set in the script.
