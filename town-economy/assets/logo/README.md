# Golden Town — logo

Everything here is generated by `scripts/build-logo.js`. Edit that script and
re-run it; do not hand-edit the SVGs, or the family will drift out of
alignment with itself.

```bash
npm --prefix /tmp/logo-tools install opentype.js
NODE_PATH=/tmp/logo-tools/node_modules:/opt/node22/lib/node_modules \
  node scripts/build-logo.js
```

opentype.js outlines the wordmark and Playwright renders the PNGs. Neither is
a project dependency — they are build-time tools for an asset that changes
about once a year, and the SVGs they produce are committed.

## The mark

Three buildings of rising height on a common base. Read it as a town, or read
it as the columns of a rising chart — it is the same drawing either way, which
is the whole idea, since the game is a town whose economy is the thing you
actually play with.

The bodies are deliberately equal-width bars and the roofs deliberately
pitched: an early draft used bare chevrons with no bodies and read, to
everyone who saw it, as a mountain range.

## Which file to use

| File                          | Use                                                              |
| ----------------------------- | ---------------------------------------------------------------- |
| `mark.svg`                    | Mark alone, one gold ramp. Small sizes, favicons, watermarks.     |
| `mark-two-tone.svg`           | Mark with cream roofs. The default whenever it is big enough.     |
| `mark-mono.svg`               | One flat colour via `currentColor`. Embossing, print, stamps.     |
| `icon.svg` / `icon-1024.png`  | App icon on the dark plate. This is the store icon.               |
| `icon-gold.svg`               | Inverted alternate — dark mark on gold. Use for contrast on dark. |
| `logo-horizontal-<lang>.svg`  | Wide spaces: headers, footers, press kits.                        |
| `logo-stacked-<lang>.svg`     | Square-ish spaces: title screen, splash, store art.               |
| `…-<lang>-dark.svg`           | The same two lockups in solid dark, for light backgrounds.        |

`<lang>` is `tr` (ALTIN KASABA) or `en` (GOLDEN TOWN).

## Rules

**Gold on dark, dark on light.** The gold lockups lose nearly all their
contrast on a light surface — that is what the `-dark` files are for. Never
tint the gold version to fix it.

**Colours come from `src/theme.ts`.** The gold ramp is `GOLD_GRADIENT`, the
plate is the app's own background browns, and the dark is `COLORS.onLight`.
If the theme's gold ever changes, change it there and re-run the script.

**Clear space:** keep at least the width of one building body clear on every
side of the mark.

**The icon PNGs are square on purpose.** Both stores apply their own corner
mask; baking a radius in leaves a pale halo inside theirs.

**Do not** re-draw the mark in strokes, outline it, add a drop shadow, stretch
it, or re-space the wordmark. The tracking is set in the script (`TRACKING`)
because Cinzel is a Roman capital face and closes up badly at default spacing.
